## Working style
- Research existing contrib solutions before building custom code.
- Favor Drupal coding standards, dependency injection, and secure implementation patterns.
- Prefer CLI generators and configuration-driven workflows over manual setup where possible.
- Add tests for production code and validate with Drupal coding and static analysis tools.

Use this skill for Drupal module or theme development, hooks, services, configuration, migrations, testing, or Drush-based workflows.
