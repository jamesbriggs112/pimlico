# Pimlico theme

The Pimlico Road theme, generated from `four_starterkit` (see `generator` in `pimlico.info.yml`). Additional information on generating themes can be found in the [Starterkit documentation](https://www.drupal.org/docs/core-modules-and-themes/core-themes/starterkit-theme).

How the theme is written is in [docs/front-end-conventions.md](../../../../docs/front-end-conventions.md).
