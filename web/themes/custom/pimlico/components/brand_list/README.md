# Brand list

Figma "A / Brand list · hover": a linen section of centred brand names in Display L, with an eyebrow, intro and a Yellow "Discover every brand" button.

On desktops with a mouse, hovering (or keyboard-focusing) a name turns it italic, fades the other names to 20% and brings that brand’s photograph up from behind the list, alternating left and right at ±3°. 350ms ease-out, CSS only (`:has()`). Touch and small screens show the names only.

Newson’s Yard "Resident brands" uses it; the paragraph comes in phase 4 with the Brand content type.
