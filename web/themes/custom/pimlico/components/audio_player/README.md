# Audio player

Figma "Audio player" for podcast episodes: a dark panel with the 64px Media control, the episode meta in yellow (it changes to "Now playing · 00:12 / 38:04"), a Fraunces title and a thin, seekable progress bar. Optional transcript link.

It starts as a native `<audio controls>` element, so the episode still plays without JavaScript; the script swaps in the designed controls.
