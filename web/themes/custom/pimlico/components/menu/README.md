# Menu

A list of `text_link` links for menus other than the main navigation: footer columns, the legal row (`size: small`, `inline: true`) and the secondary links in the mobile menu. The current page is marked `aria-current` and underlined (`text-link--current`), except in the footer, which sets `--text-link-current-underline-color: transparent`.

Used by `templates/menu/menu.html.twig` for every menu without a more specific template.
