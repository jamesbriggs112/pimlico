# Filter bar

Figma "Filter link" in the Brands, Dine and News filter bars: category links in Label/Nav. The active filter is underlined (3px offset, `aria-current`); hover moves the underline to 6px. Centred (Brands, News) or left-aligned (Dine). Scrolls sideways on mobile.

The listings in phase 4 feed it from Views exposed filters.
