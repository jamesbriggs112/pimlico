# Featured story

Figma News "Featured story": a 3:2 image beside the lead story's meta, Display L title, standfirst, reading time and "Read the story" link. With `url`, the text column is the link. Without, it is the press "Section · Publication" block, with the publication logo above the meta. The press template adds the `featured-story--publication` class, which on mobile puts the logo and meta above the image and the standfirst below it (Figma 175:4746).
