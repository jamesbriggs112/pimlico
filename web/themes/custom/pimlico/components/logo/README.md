# Logo

The Pimlico Road wordmark (`brand: pimlico_road`) or the Grosvenor logo (`brand: grosvenor`), drawn inline so its colour follows `tone`.

## Usage

Use in the header, footer and mobile menu. Pass `url` to link it, usually to the home page. The SVG scales to the width of its container, so set a width on the wrapper.
