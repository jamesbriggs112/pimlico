# Info band

The dark-grey band behind Figma’s brand "Find the showroom" and the press "Source" section: an optional yellow eyebrow, a white Display L heading, optional detail rows (compact `info_row`s: Address, Opening hours, Trade, Contact…) and Yellow buttons, beside a photograph or the street map.

- A framed photo (640×800) is dropped on mobile, as designed.
- `media_fill: true` is for the map: it takes half the band edge to edge, and sits full width below the text on mobile.
- Buttons with `external: true` open in a new tab with an ↗ marker.
