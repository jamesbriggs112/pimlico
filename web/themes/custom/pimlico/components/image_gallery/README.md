# Image gallery

Figma brand "Gallery": a heading and photo credit, then rows of photographs repeating Figma’s pattern (landscape + portrait, two landscapes, three portraits, portrait + landscape). Each photo is cropped to its slot: landscapes 3:2, portraits 4:5. Widths follow the shapes, so every row is one height.

On mobile it becomes a single 300px-tall swipe track with previous and next buttons (disabled at either end). The track is focusable, so it can also be scrolled with the arrow keys.
