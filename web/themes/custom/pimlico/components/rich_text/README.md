# Rich text

Figma "Rich text": formatted text from the editor at a 760px reading measure, with 24px between blocks. Styles h2 (Display M), h3 (Fraunces Regular 26), h4 (dark eyebrow), paragraphs, bold, italic, bulleted lists (pumpkin rule) and numbered lists (pumpkin numbers), and underlined links.

The "Rich text" paragraph (`text_wysiwyg_`) and the policy pages use it.
