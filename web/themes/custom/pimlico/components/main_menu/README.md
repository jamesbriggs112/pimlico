# Main Menu

The header navigation, rendered from the `main` menu through `templates/menu/menu--main.html.twig`.

- **Desktop:** the first `split` items (default 3) sit left of the logo and the rest right, as in Figma "Header". The current section is underlined.
- **Mobile:** the same links, stacked, in the mobile menu (Figma "Mobile nav item").
- **One level only:** child menu items are not shown; there are no drop-downs.
